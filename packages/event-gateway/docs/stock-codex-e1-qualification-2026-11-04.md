## Claim semantics and safeguards

The adapter now passes `--resume` and returns `command_accepted` only after the stock command exits zero. CLI help says resume failure can warn while the queue command still succeeds, so the ACK remains queue-command acceptance only. Launch failure, nonzero exit, timeout, and cancellation after launch remain unknown outcomes. The ACK is not a client-recorded receipt or turn-lifecycle signal.

Focused gateway tests cover the exact queue argv, exit-zero behavior when CLI stderr contains a resume warning (acceptance remains command-only), Popen termination/reap timeout reporting, and the existing queue/ACK recovery paths. `test_duplicate_and_command_acceptance_never_relaunch` proves a duplicate accepted delivery does not invoke the CLI twice; `test_lost_ack_survives_restart_and_retries_only_the_stored_ack` proves lost cloud ACK recovery resends only the stored ACK; `test_timeout_after_launch_is_ambiguous_and_never_replayed_after_restart` proves an ambiguous client submission is not replayed.

Probe-helper tests cover A/B history isolation, pre-TUI request baselines, private-safe protocol-shape capture, title-generation classification (unknown requests remain unknown), client-visible ordering, the exact busy gate, and bounded Popen cleanup. Scratch mutations that reduced matching to reference-only, moved the baseline after TUI startup, reversed the client-visible ordering comparator, or removed Popen reap each made the corresponding tests fail; restoring the implementation returned the suite to green. A scratch fixture with the title warning removed also made the CLI-warning regression test fail; restored focused tests passed.

Official app-server docs describe persistent `thread/start` and `thread/resume` operations keyed by saved thread ID; they do not promise queue receipts or idempotency: [Codex app-server](https://learn.chatgpt.com/docs/app-server#lifecycle-overview), [Codex app-server thread resume](https://learn.chatgpt.com/docs/app-server#continue-a-stored-session).

No E2 contract or production route follows from this result. Independent client breadth and live activation retain their own gates.
